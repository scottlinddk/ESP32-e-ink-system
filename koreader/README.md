# KOReader plugin

`einkdisplay.koplugin` shows a registered device's layout on a Kindle Paperwhite or another
KOReader e-reader, using the same device-feed protocol as the ESP32 firmware.

Setup, settings and troubleshooting: [docs/KINDLE_KOREADER.md](../docs/KINDLE_KOREADER.md).

```sh
luajit koreader/spec/run.lua
```
